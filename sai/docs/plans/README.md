# Archived SAI plans (2026-07-18 to 2026-07-19)

Frozen design and implementation plans from the SAI SDK's first two days, kept
for provenance like `docs/plans/` and `docs/superpowers/`. They describe intent
at the time, not current behaviour or scope: names, targets and limitations in
them have since changed. Cite them; don't edit or add to them. For the current
SDK start at [`sai/README.md`](../../README.md) and the
[portable contract](../portable-contract.md).
