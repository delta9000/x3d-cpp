- **PROTO-INTERFACE-STATE** [major/OPEN] — §4.4.2.2; 4.4.4.2; 4.4.4.3: Prototype interface fields without IS targets have no independent runtime field state or event endpoint.

The store seeds initializeOnly/inputOutput fields from the fieldValue override or the interface default and gives inputOutput fields a set (echoed as _changed) plus a get; inputOnly fields get a set (route sink); outputOnly fields get a get (route source); initializeOnly stays value-only.
