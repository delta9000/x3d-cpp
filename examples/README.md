# x3d-cpp examples

| Directory or file | What it is |
|---|---|
| `01_*.cpp`, `02_*.cpp`, `03_*.cpp` | Headless programs on the public `x3d::sdk` façade; built and run as CTests |
| `embed_minimal/` | A downstream project that consumes the installed package |
| `cpu_raster/`, `poc_renderer/`, `x3d2svg/` | Renderers built on the extraction feed; off by default |
| `asset_import/` | Converter from foreign asset formats to X3D |
| `sai_host/` | Headless host for the native SAI backend |

What each one shows, its build option and its page are in
[docs/wiki/reference/examples/index.md](../docs/wiki/reference/examples/index.md).
