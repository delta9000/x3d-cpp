# Headless CPU rasterizer (`x3d_cpu_raster`)

An out-of-SDK consumer of x3d-cpp, off by default.

```sh
mise run cpuraster
```

Documentation: [docs/wiki/reference/examples/cpu-raster.md](../../docs/wiki/reference/examples/cpu-raster.md)
(build options, command-line flags, coverage and scope). All examples are
listed in [docs/wiki/reference/examples/index.md](../../docs/wiki/reference/examples/index.md).
